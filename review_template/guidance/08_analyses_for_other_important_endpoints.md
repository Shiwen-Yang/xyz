# Instructions: Analyses for Other Important Endpoint(s):

Original source: `content/8_analyses_for_other_important_endpoints.tex`.

Repeat the complete analysis block under a named ## endpoint heading for every other statistically important endpoint. Keep each method, analysis population, missing-data rule, and alpha allocation attached to its endpoint. Use endpoint-specific evidence IDs, e.g. OTHER_ANALYSIS.PFS.METHOD. For section 8, do not accidentally relabel other-endpoint analyses as primary-endpoint analyses.

## OTHER_ANALYSIS.PRIMARY — Primary analysis

Group containing the main analysis for the named endpoint.

## OTHER_ANALYSIS.METHOD — statistical method

Describe the specified method, e.g. stratified log-rank test, CMH for response rate, or ANCOVA; include relevant estimand details when provided.

## OTHER_ANALYSIS.COVARIATES — covariates or strata

List the covariates/strata used in this analysis; distinguish them from randomization factors.

## OTHER_ANALYSIS.SET — analysis set

Describe membership rules and how subjects are analyzed, rather than only stating ITT/mITT/PP. ITT example: all randomized subjects as randomized; mITT example: randomized and at least one treatment, as randomized; PP example: no major protocol violations. Use the sponsor definitions, which may differ from these examples. For primary analyses, if not as randomized, include the sponsor justification or flag a potential request for justification. For therapeutic/preventive vaccines, identify justification for mITT/PP when relevant.

## OTHER_ANALYSIS.MISSING — missing data handling

Describe missing-data procedures and, for time-to-event endpoints, censoring rules and time points. Keep primary handling distinct from sensitivity analyses; examples include multiple imputation and tipping-point analyses.

## OTHER_ANALYSIS.ALPHA — α-level

State one/two-sided alpha and multiplicity control across endpoints/hypotheses. Include applicable adjustment/gatekeeping/Bonferroni or other procedures, and connect to interim testing. Do not assume overall and local alpha are identical.

## OTHER_ANALYSIS.SENSITIVITY — Sensitivity/supportive

Describe alternative methods, populations, and missing-data procedures, e.g. a Cox model for PFS or Fisher exact test for response rate.

## OTHER_ANALYSIS.SUBGROUP — Subgroup analysis

Describe planned subgroup analyses. Check whether age, sex, and race analyses are specified when applicable; distinguish a reviewer request from a sponsor plan.
