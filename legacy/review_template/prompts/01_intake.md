# Document intake prompt

Read the attached review instructions and source register before extracting report content. Identify every supplied document by ID, identifier, version/date, and role. Confirm which is the current main protocol; do not assume newer background material supersedes it.

Report which documents you can actually read. Build a concise map of protocol sections for objectives, design, endpoints, hypotheses, analysis populations/methods, missing data, multiplicity, interim analyses, and sample size. Include section labels, PDF positions and printed page labels where accessible. List background documents relevant to submission history or prior agreements separately.

Flag unreadable pages, truncated attachments, attachment limits, missing referenced documents, and version conflicts. Do not draft the review yet or claim exhaustive coverage unless you could search the whole relevant material. Ask only for missing information that materially affects the requested extraction.
