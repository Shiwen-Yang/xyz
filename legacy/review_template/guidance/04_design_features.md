# Instructions: Design Features:

Original source: `legacy/tex/content/4_design_features.tex`.

Describe the study design. For a single-arm study omit inapplicable allocation-ratio, stratification, blinding, and comparative treatment-arm bullets after confirming applicability; describe the intervention/regimen in the population or other-features text. Do not lose the only intervention description when removing comparator fields. Do not discuss interim looks or non-inferiority design here; put those in sections 9 and 6.

## DESIGN.POPULATION — Study population

Describe key target-population characteristics and important eligibility boundaries, such as age range and disease status.

## DESIGN.RANDOMIZATION — Treatment Allocation and Randomization

Describe stratified randomization, minimization, non-randomized concurrent control, or single-arm design.

## DESIGN.ALLOCATION_RATIO — allocation ratio

State the ratio and named arms, e.g. 1:1 or 2:1. Omit if not applicable.

## DESIGN.STRATA — stratification factors

List all randomization factors with categories if stated, e.g. disease stage, site, or region. State none only if supported.

## DESIGN.BLINDING — Blinding

State open label, single blind, or double blind and specify who is blinded and who can access treatment allocation before database lock (subjects, investigators, surgeons, outcome evaluators). Omit for single-arm designs per this template.

## DESIGN.ARMS — Treatment Arms

Group containing arm descriptions; a simple rectangular table may replace this group. Add a named arm entry for every additional arm. Omit the comparative group for single-arm designs.

## DESIGN.ARM.EXPERIMENTAL — experimental

Describe the experimental intervention, including dose, route, and schedule where relevant; repeat with explicit arm names/IDs if multiple experimental arms.

## DESIGN.ARM.CONTROL — control

Describe standard of care, placebo, or other comparator, with regimen as relevant; repeat for additional controls.

## DESIGN.SITES — Site(s)

Describe approximate site counts and countries/regions. Note the US population percentage if available.

## DESIGN.OTHER — Other features

Describe unusual important features, such as a delay between randomization and manufacturing/treatment or lot-consistency requirements before pooling efficacy data. Omit if none after reviewer confirmation. If a schematic is necessary, flag it for reviewer insertion in Word; the initial Markdown build does not embed figures.
