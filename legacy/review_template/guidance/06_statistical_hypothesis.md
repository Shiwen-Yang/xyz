# Instructions: Statistical Hypothesis:

Original source: `legacy/tex/content/6_statistical_hypothesis.tex`.

State explicit hypotheses and define every parameter, treatment direction, and margin. If the protocol gives no formal hypothesis, report that it was not located rather than constructing one without labeling it as reviewer interpretation.

## HYPOTHESIS.STATEMENT — Hypotheses and parameters

State H0 and H1, with parameter definitions and endpoint linkage. Use standard math such as $H_0: \mathrm{HR}=1$ versus $H_1: \mathrm{HR}\ne1$. Do not use custom TeX macros such as \hnull or \halt.

## HYPOTHESIS.MARGIN — Non-inferiority/equivalence margin

If applicable state the margin and sponsor rationale. Separate the stated justification from reviewer assessment; omit if not applicable.

## HYPOTHESIS.SUCCESS — Study success criterion

Describe how success is established when testing multiple hypotheses, including whether all or any must succeed and the testing sequence if stated. Omit if not applicable.
